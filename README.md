# Pixel Campaign Website

เว็บ static ฟรีสำหรับ GitHub Pages ธีมพิกเซลเกมของ
`พรรคไม่พักเพราะรักนวมินทร์เตรียมพัฒน์`

## Features

- หน้าเข้าเว็บพร้อมปุ่ม `เข้ารับชม`
- HomePage พร้อมเมนูข้ามหน้า
- Hover pop effect
- Transition จอดำพร้อมตัวละครเดินลงท่อ
- หน้านโยบายแบบ scroll
- หน้าสมาชิกพร้อม loading style Minecraft overworld
